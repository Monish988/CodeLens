# CodeLENS Project Summary & Workflow

## 1. Project Summary
CodeLENS is a high-performance, local-first developer tool designed for deep codebase comprehension. Unlike standard text search, CodeLENS uses Abstract Syntax Trees (AST) to understand code structure (functions, classes, variables) and visualizes these relationships through interactive dependency graphs. It emphasizes privacy, reliability, and speed, operating entirely on the user's local machine.

---

## 2. Core Workflow
1.  **Workspace Initialization**: The user selects a local directory.
2.  **Indexing & Parsing**: 
    - The backend scans the directory (using `chokidar` for real-time updates).
    - Files are parsed via `Tree-sitter` to extract entities (definitions and references).
    - Data is indexed into a local `SQLite` database with FTS5 for sub-100ms searching.
3.  **Global Search & Dashboard**: 
    - Full-text search with keyword highlighting and snippet previews.
    - Result rankings prioritized by entity type (Functions > Classes > Variables).
4.  **Visual Dependency Analysis**:
    - Generates interactive graphs using `XYFlow` (React Flow) to visualize call chains.
    - Supports deep node navigation, automatic filter toggling, and neighborhood highlighting.
5.  **Context Management**: 
    - Group related files into "Context Buckets" to focus AI analysis and narrow search scope.
6.  **Search History**:
    - Persistent tracking of all queries, result counts, and timestamps in `localStorage`.
    - One-click "Re-run Search" functionality from the dedicated History page.

---

## 3. Technology Stack
- **Frontend**: React 19, Vite, XYFlow (React Flow), Lucide React.
- **Backend**: Node.js (Express), TypeScript, `tsx`.
- **Database**: SQLite (`better-sqlite3`) with FTS5 virtual tables and advanced JOIN logic for metadata retrieval.
- **Code Analysis**: `Tree-sitter` for robust AST parsing across JS/TS/JSX/TSX.
- **AI**: Gemini 2.0 (via OpenRouter) for context-aware architectural summaries.

---

## 4. File Structure & Descriptions

### Root Directory
- `/README.md`: Primary documentation for setup and usage.
- `/PROJECT_OVERVIEW.txt`: (This file) Architectural map and workflow summary.
- `/codelens.db`: Local SQLite database storing all indexed structural metadata.

### src/backend (The Logic Layer)
- `server.ts`: Express API layer handling search, indexing status, and graph generation.
- `/db/connection.ts`: Database schema definition and migration logic.
- `/indexer/Indexer.ts`: Orchestrates file system watching and the parsing pipeline.
- `/indexer/Parser.ts`: Language-aware analysis engine using Tree-sitter.

### src/pages (The UI Layer)
- `DashboardPage.jsx`: Central search hub with high-fidelity result cards and snippet highlighting.
- `ExplorePage.jsx`: Dual-pane file browser and symbol outline explorer.
- `DependencyGraphPage.jsx`: Advanced graph visualization with smart navigation and auto-focus logic.
- `HistoryPage.jsx`: Interactive history manager with statistics, filters, and JSON export.
- `ContextsPage.jsx`: Workspace subset manager for targeted analysis.

### src/components (Reusable Elements)
- `/layout/Layout.jsx`: Main application shell with sidebar navigation.
- `/ui/`: Atomic UI components (Buttons, Modals, Cards, Badges).

---

## 5. Development Commands
- `npm run dev:all`: Concurrent execution of Vite frontend and Express backend.
- `npm run server`: Dedicated backend runner.
- `npm run dev`: Dedicated frontend runner.
